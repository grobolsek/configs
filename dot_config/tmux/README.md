# tmux config

Personal tmux setup (tmux 3.8, Wayland). Prefix is **Ctrl+Space**.

Everything is split into small files that `tmux.conf` loads in order. Colors
come from Noctalia, so the whole UI (status bar, menus, popups, fzf helpers)
follows the desktop theme live.

The status bar has two rows: **row 1** is the menu bar and is always there;
**row 2** appears only while tmux shows a message or a prompt (see
[Status bar](#status-bar)).

```
~/.config/tmux/
├── tmux.conf            entry point: only sources conf/*.conf, in order
├── colors.conf          generated by Noctalia, do not edit
├── conf/
│   ├── options.conf     prefix, general settings, clipboard
│   ├── theme.conf       colors, row 1 (menu bar), row 2 (messages), popups + menus
│   ├── ui.conf          command shortcuts: helper, tool, split-right, …
│   ├── keys.conf        every keybinding
│   ├── menu.conf        the prefix Space menu
│   └── plugins.conf     plugins (TPM loads last)
├── scripts/
│   ├── lib/ui.sh        shared look + helpers for the fzf popups
│   ├── keys.sh          prefix ?  searchable key list
│   ├── cmd.sh           prefix :  command palette
│   ├── jump.sh          prefix w  session / window / pane switcher
│   ├── preview.py       preview pane for jump.sh
│   └── line2.sh         shows and hides row 2
└── plugins/             installed by TPM (not part of the config)
```

## Keys

`prefix` = press **Ctrl+Space**, let go, then the key.
When you are not sure, press **prefix Space** (menu) or **prefix ?** (search all keys).

### Everyday

| Keys | Does |
|---|---|
| `prefix Space` | menu with the most used actions |
| `prefix ?` | search every keybinding; Enter runs it |
| `prefix \|` / `prefix -` | split right / split down (keeps the directory) |
| `prefix c` | new window (keeps the directory) |
| `prefix Tab` | last window |
| `prefix z` or `Alt+z` | zoom pane |
| `prefix x` / `prefix &` | kill pane / kill window (asks first) |
| `prefix r` | resize mode (see below) |
| `prefix w` | session switcher |
| `prefix d` | detach |
| `Alt+1` … `Alt+9` | go to window 1–9 (no prefix) |
| `Ctrl+h/j/k/l` | move between panes and vim splits (no prefix) |
| `prefix Ctrl+l` | clear screen (plain Ctrl+l moves panes) |

### Tools (popups)

| Keys | Does |
|---|---|
| `prefix g` | lazygit in the current directory |
| `prefix t` | scratch shell in the current directory |
| `prefix :` | command palette with suggestions |
| `prefix e` | plain tmux command line (Tab completes) |
| `prefix R` | reload the config |

### Prompts

Like every prompt, these open on row 2, which goes away again when you
answer or press Esc.

| Keys | Asks for |
|---|---|
| `prefix ,` / `prefix $` | rename window / session |
| `prefix T` | pane title |
| `prefix '` | window index to go to |
| `prefix .` | index to move the window to |
| `prefix f` | text to find in windows |
| `prefix /` | a key to explain |

### Copy mode (`prefix [`)

vim keys. `v` select, `Ctrl+v` block, `y` copy, `/` search, `q` quit.
Everything copied goes to the system clipboard (`wl-copy`). With the mouse:
drag, double click (word) and triple click (line) copy right away.

### Resize mode (`prefix r`)

`h j k l` (or arrows) resize by 2, `H J K L` by 10, `=` equalize, `z` zoom.
`Esc`, `q`, `Enter` or any other key leaves it.

### Session switcher (`prefix w`)

| Key | Does |
|---|---|
| `Enter` | switch to the highlighted session / window / pane |
| `Tab` | mark (several) |
| `Ctrl+x` | kill marked (or highlighted) |
| `Alt+m` | move what you marked with Tab: onto a **window**, marked panes join it; onto a **session**, they become windows there |
| `Alt+↑` / `Alt+↓` | reorder window |
| `Ctrl+r` | rename |
| `Ctrl+n` | new session |
| `Ctrl+t` | tmux's own tree instead |

### Command palette (`prefix :`)

Type to filter tmux commands. `Enter` on a suggestion opens the command line
prefilled so you can add arguments. `Enter` after typing arguments runs it
directly. `Alt+Enter` runs the highlighted command with no arguments.

### Plugins

| Keys | Does |
|---|---|
| `prefix I` / `prefix U` | install / update plugins |
| `prefix Alt+u` | remove plugins no longer listed |
| `prefix Ctrl+s` / `prefix Ctrl+r` | save / restore sessions (resurrect) |

Sessions are also saved every 15 minutes and restored when tmux starts
(continuum). A manual save shows "Tmux environment saved!" on row 2.

## Status bar

On top, two rows.

**Row 1, the menu bar**, is always there:

- **Left:** mode block, then the session name. The mode block changes color
  and text: `NORMAL`, `PREFIX` (after Ctrl+Space), `COPY`, `RESIZE`.
- **Middle:** windows. The current one is highlighted, `Z` marks a zoomed one.
- **Right:** current directory, git branch, clock. While a mode is active
  this is replaced by hints for that mode's keys.

**Row 2, the message row**, exists only while tmux shows a message or a
prompt, whatever sent it: a key, the menu, a script, a plugin (also ones you
add later) or tmux itself, e.g. an error. It goes away when the message times
out (`display-time`, 1.5s), when you press a key, or when you answer or cancel
the prompt. While it is there, the panes are one row shorter.

## How it is built

**Load order** (`tmux.conf`) matters: `options` → `theme` → `ui` → `keys` →
`menu` → `plugins`. `ui.conf` must load before `keys.conf` and `menu.conf`,
because they use its shortcuts. TPM must load last.

**Colors.** `theme.conf` sets fallback colors as tmux options (`@bar`, `@fg`,
`@c_accent`, …), then loads `colors.conf`, which Noctalia regenerates and
reloads on every theme change. Everything else only refers to the options
(`#{@c_accent}`), never to hex values, so a theme change applies at once.
The fzf scripts read the same options (`scripts/lib/ui.sh`).

**Shortcuts** (`conf/ui.conf`) are named commands that keys and menu share:

| Shortcut | Use |
|---|---|
| `helper -T "${T}Name " "$SCRIPTS/x.sh"` | fzf helper popup |
| `tool -T "${T}Name " program` | big popup in the pane's directory |
| `split-right`, `split-down`, `new-window-here` | split / new window in the pane's directory |
| `rename-window-prompt`, `rename-session-prompt` | ask for the new name |
| `kill-pane-prompt`, `kill-window-prompt` | ask, then kill (same as `x` and `&`) |

`helper` holds several commands, so it must be the **last** command in a
binding (tmux drops anything after it).

The menu needs these shortcuts for anything with a `#{…}` format: a menu
expands the formats in its commands (twice) before running them, so `#W`
written in `menu.conf` would already be the window name there, and a name
containing `'` would break the quoting. Use `%1` in prompt templates, not
`%%`: `%%` also breaks text that contains `'`.

**Row 2** (`conf/theme.conf`, `scripts/line2.sh`). tmux has no event for "a
message appeared / went away", so two things tmux draws stand in for one:

- `message-format` is drawn for every message and prompt. A `#()` job in it
  runs `line2.sh show`, which adds row 2 (`status 2` on that session).
- `status-format[1]`, row 2's own content, is drawn only when nothing covers
  row 2. A `#()` job in it runs `line2.sh hide`, which removes row 2.

Because this hooks into how tmux draws messages, not into particular keys,
it covers everything, including plugins added later. The `@line2_shows` /
`@line2_hides` options change on every show and hide, so tmux re-runs the
jobs for each new message instead of reusing a cached result. Until row 2
exists (a few ms), a message is drawn on row 1 as one invisible cell. When
several terminals are attached to the same session, row 2 goes away only
once each of them has drawn it free (`@line2_free_<pid>`).

**fzf helpers** (`scripts/`) all source `lib/ui.sh`, which provides:

| Helper | Does |
|---|---|
| `ui_fzf` | fzf with the shared look; extra args override |
| `ui_hint key word …` | header line like `↵ run · Esc close` |
| `ui_client` | the client that opened the popup |
| `ui_later 'cmds'` | run tmux commands after the popup has closed |
| `ui_prompt label text [template]` | open a prompt from a script |

## Adding things

- **A key:** add it to `conf/keys.conf` with a `-N "note"`, so `prefix ?`
  lists it. If it should be in the menu, add a row to `conf/menu.conf`
  (anything with `#{…}` goes behind a shortcut in `ui.conf`). If it's
  important enough, add it to the `H_PREFIX` hint in `conf/theme.conf`.
- **A prompt or message:** just use `command-prompt`, `confirm-before` or
  `display`; it lands on row 2 by itself.
- **A popup tool:** `bind -N "Thing" k tool -T "${T}Thing " program`.
- **A new fzf helper:** create `scripts/x.sh`, start it with
  `. "$(dirname "$0")/lib/ui.sh"`, use `ui_fzf` / `ui_hint`, and bind it
  with `helper`.
- **A plugin:** add `set -g @plugin '…'` in `conf/plugins.conf` above the
  `run` line, reload, then `prefix I`.

After any change press `prefix R`. To check for errors without applying
anything: `tmux source-file -n ~/.config/tmux/tmux.conf`.

**Note:** Alt+Shift switches the keyboard layout here, so don't use bindings
that need Alt plus a shifted key (like `Alt+:`).
